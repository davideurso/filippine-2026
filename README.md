# Mappa Filippine 2026

Mappa interattiva dell'itinerario nelle Filippine.

Il sito viene pubblicato tramite GitHub Pages dal file `index.html`.

Per gli aggiornamenti successivi:

1. sostituire `index.html` con la nuova versione;
2. aprire PowerShell nella cartella;
3. eseguire `./pubblica-mappa.ps1`.
